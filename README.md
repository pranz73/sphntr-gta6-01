An original open world crime game set in Port Azura. Play as a street runner working three jobs for fixer Vera Solano: deliver a dockside package, steal a marked car, and race a chain of checkpoints while evading a growing police response. The city includes walkable streets, stealable and drivable cars, traffic, pedestrians, a wanted system, close combat and pistol combat, health pickups, a minimap, synthesized audio, and a free roam ending. Story progress, cash, and position save in your browser.

## Run

Run `node serve.ts`, then open the local page shown by the server. To create the handover dossier, run:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

## Controls

- **WASD / arrow keys:** walk or drive
- **Shift:** run on foot
- **E or F:** enter or exit a nearby car; interact with Vera at the mission marker
- **Space:** punch a nearby target on foot
- **Mouse click:** aim and fire the pistol
- **R:** reload
- **P or Escape:** pause
- **M:** toggle sound
- **Enter:** start a new run; **C:** continue a saved run; **X:** erase the save from the title screen
